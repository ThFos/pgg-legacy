Πώς να αλλάξεις Skin στον PGG Legacy

Από PGG Legacy · 18 Απριλίου 2026

Στον PGG Legacy μπορείς να παίζεις με οποιοδήποτε skin θέλεις — ακόμα και αν χρησιμοποιείς cracked account. Το σύστημα skin του server υποστηρίζει αλλαγή απευθείας μέσα από το παιχνίδι, χωρίς να χρειαστεί να βγεις.

Περιεχόμενα: Μέσω URL Μέσω Username Tips & Μορφή Εντολές

🔗 Μέθοδος 1: Μέσω URL

Αν έχεις το skin σου ανεβασμένο online (π.χ. από το NameMC ή οποιοδήποτε image host), χρησιμοποίησε αυτή τη μέθοδο:

📋 Βήματα
  1. Βρες το direct URL της εικόνας του skin σου (.png)
  2. Συνδέσου στον server: play.PGGlegacy.gr
  3. Γράψε στο chat: /skin url [το URL σου]
  4. Το skin σου αλλάζει αυτόματα!
💡
Παράδειγμα: /skin url https://i.imgur.com/example.png
Βεβαιώσου ότι το URL τελειώνει σε .png και είναι direct link — όχι σελίδα gallery.

👤 Μέθοδος 2: Μέσω Username

Αν θέλεις να χρησιμοποιήσεις το skin ενός άλλου Minecraft παίκτη, μπορείς να το αντιγράψεις απευθείας:

📋 Βήματα
  1. Βρες το Minecraft username που έχει το skin που θέλεις (π.χ. από το NameMC)
  2. Συνδέσου στον server
  3. Γράψε: /skin set [username]
  4. Το skin του παίκτη εφαρμόζεται στον χαρακτήρα σου!
💡
Παράδειγμα: /skin set Notch
Αυτό θα εφαρμόσει το skin του παίκτη Notch στον χαρακτήρα σου.

📐 Tips & Απαιτήσεις Μορφής

⚠️
Τα skins πρέπει να είναι 64×64 pixels ή 64×32 pixels (classic format) σε μορφή PNG. Άλλες διαστάσεις δεν γίνονται δεκτές.
🌐 Πού να βρεις Skins
  • NameMC.com — Τεράστια συλλογή με χιλιάδες skins
  • MinecraftSkins.com — Εναλλακτικό site με πολλές επιλογές
📤 Πού να ανεβάσεις το PNG σου
  • Imgur.com — Δωρεάν image hosting, δίνει direct .png link
  • Οποιοσδήποτε image host που παρέχει direct link που τελειώνει σε .png
💡
Γρήγορη διαδικασία: Κατέβασε skin → Ανέβασε στο Imgur → Δεξί κλικ στην εικόνα → "Copy image address" → Χρησιμοποίησε το link στο /skin url [link]

📋 Εντολές Skin — Γρήγορη Αναφορά

Command Χρήση
/skin url [URL] Αλλαγή skin μέσω direct URL εικόνας (.png)
/skin set [username] Αντιγραφή skin από άλλον Minecraft παίκτη

Δοκίμασε το νέο σου skin στον server!
