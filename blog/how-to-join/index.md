Ψάχνεις τον καλύτερο **Ελληνικό Minecraft Roleplay Server**; Ο **PGG Legacy** προσφέρει μια μοναδική εμπειρία **Minecraft RP & Survival** στην έκδοση **Java Edition 1.20.1**, με Proximity Voice Chat, custom plugins και ενεργή ελληνική κοινότητα.

Αν αναρωτιέσαι **πώς να μπεις στον Minecraft server** μας, ακολούθησε τα παρακάτω απλά βήματα και ξεκίνα το παιχνίδι σε λιγότερο από 2 λεπτά!

<h2 id="step1">1. Πάρτε την IP του Minecraft Server &amp; Μπείτε στο Discord</h2>

- Επισκεφθείτε την επίσημη ιστοσελίδα μας: **[pgglegacy.gr](https://pgglegacy.gr/)**.
- Αντιγράψτε (**Copy**) την επίσημη **Minecraft Server IP**: `play.PGGlegacy.gr`.
- Πατήστε τον σύνδεσμο για να συνδεθείτε στον [Discord Server](https://discord.gg/Ks7NtXhtwV) της ελληνικής κοινότητάς μας.

<h2 id="step2">2. Ανοίξτε το Minecraft Java Edition στην Έκδοση 1.20.1</h2>

- Ανοίξτε τον **Minecraft Launcher** στον υπολογιστή σας.
- Επιλέξτε την έκδοση **Java Edition 1.20.1**.
- Πατήστε **Play** (Έναρξη).

<h2 id="step3">3. Προσθέστε τον Server &amp; Πάρτε τον Κωδικό Verification</h2>

- Στο αρχικό μενού του παιχνιδιού, επιλέξτε **Multiplayer** → **Add Server**.
- Στο πεδίο Server Address, κάντε επικόλληση (**Paste**) την IP: `play.PGGlegacy.gr`.
- Πατήστε **Join Server** για να συνδεθείτε.
- Κατά την πρώτη είσοδο, θα εμφανιστεί στην οθόνη ένας **μοναδικός κωδικός επιβεβαίωσης (Verification Code)**. Κάντε **Copy** αυτόν τον κωδικό.

<h2 id="step4">4. Ταυτοποίηση (Verification) στο PGG Legacy Discord Bot</h2>

- Μεταβείτε στην εφαρμογή του **Discord**.
- Βρείτε το **PGG Legacy Bot** στη δεξιά λίστα μελών του Discord server μας.
- Στείλτε στο bot σε **Προσωπικό Μήνυμα (DM)** τον κωδικό επιβεβαίωσης που αντιγράψατε από το παιχνίδι.

> ⚠️ **Αντιμετωπίζεις πρόβλημα;**
> Αν το bot δεν σου απαντήσει, βεβαιώσου ότι επιτρέπεις μηνύματα (DMs) από members του server στις ρυθμίσεις απορρήτου του Discord. Αν το πρόβλημα συνεχίζεται, ρώτα έναν admin.

## 🎉 Είστε έτοιμοι για το Καλύτερο Ελληνικό Minecraft Roleplay!

Αφού το Discord Bot επιβεβαιώσει τον κωδικό σας, επιστρέψτε στο Minecraft και πατήστε ξανά **Join Server**. Η ταυτοποίηση ολοκληρώθηκε επιτυχώς!

Είστε πλέον έτοιμοι να εξερευνήσετε τον κόσμο, να δημιουργήσετε τον χαρακτήρα σας και να ζήσετε την απόλυτη εμπειρία στον **PGG Legacy Greek Minecraft Server**!

👉 Διάβασε επίσης: [Οι Κανόνες του PGG Legacy Server](https://pgglegacy.gr/#rules) πριν ξεκινήσεις το RP σου!

<h2 id="faq">❓ Συχνές Ερωτήσεις (FAQ)</h2>

**Παίζει ο PGG Legacy σε Bedrock Edition ή κινητό;**
Όχι, ο server λειτουργεί αποκλειστικά σε Minecraft Java Edition, έκδοση 1.20.1.

**Τι κάνω αν δεν μου εμφανίζεται κωδικός verification;**
Βγες και ξαναμπές στον server (Disconnect → Join Server ξανά).

**Το PGG Legacy Bot δεν απαντάει στο DM μου, τι κάνω;**
Βεβαιώσου ότι έχεις ενεργοποιημένα τα DMs από members του server (Discord Settings → Privacy & Safety).

**Χρειάζεται να πληρώσω για να παίξω στον PGG Legacy;**
Όχι, η σύνδεση και η διαδικασία ταυτοποίησης είναι εντελώς δωρεάν.
