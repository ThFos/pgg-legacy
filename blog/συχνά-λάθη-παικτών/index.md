# ❓ FAQ & Συχνά Λάθη Νέων Παικτών

Καλωσόρισες στον **PGG Legacy**! Για να διευκολύνουμε το ξεκίνημά σου στον server, συγκεντρώσαμε τις πιο συχνές ερωτήσεις των νέων παικτών, καθώς και τα συνηθέστερα λάθη που πρέπει να αποφύγεις.

---

## 💬 Συχνές Ερωτήσεις (FAQ)

### 1. Πώς συνδέομαι και πώς ξεκινάω στον server;

* **Server IP:** `play.PGGlegacy.gr`
* **Έκδοση:** Java Edition **1.20.1**
* **Πρώτα Βήματα:** Δες τον αναλυτικό [Οδηγό Πρώτων Βημάτων (Getting Started Guide)](https://pgglegacy.gr/blog/getting-started-guide/) για να μάθεις πώς να κάνεις τα πρώτα σου βήματα στον κόσμο μας.

### 2. Πώς μπορώ να αλλάξω το skin μου;

Μπορείς να αλλάξεις το skin του χαρακτήρα σου απευθείας in-game χρησιμοποιώντας τις ανάλογες εντολές. Δες τον αναλυτικό [Οδηγό Αλλαγής Skin](https://pgglegacy.gr/blog/αλλαγή-skin/) για όλες τις διαθέσιμες εντολές και οδηγίες.

### 3. Ποιες εντολές (Game Commands) μπορώ να χρησιμοποιήσω;

Για να δεις τη πλήρη λίστα με τις βασικές εντολές του server (spawn, home, teleport, chat modes), ανατρέξτε στον [Οδηγό Game Commands](https://pgglegacy.gr/blog/game-commands/).

### 4. Πού μπορώ να μπω στο Discord;

Μπορείς να μπεις στην παρέα μας μέσω του συνδέσμου: [Discord](https://discord.gg/Ks7NtXhtwV).

### 5. Πώς κάνω αίτηση για την Αστυνομία;

Οι αιτήσεις για το αστυνομικό σώμα γίνονται ηλεκτρονικά μέσα από την επίσημη σελίδα μας: [pgglegacy.gr/police](https://pgglegacy.gr/police).

### 6. Υπάρχει χάρτης του server;

Ναι! Μπορείς να δεις τη θέση σου, τις πόλεις και τα κτίρια σε real-time μέσω του map στη διεύθυνση: [pgglegacy.gr/map](https://pgglegacy.gr/map).

## 🚫 Συχνά Λάθη που πρέπει να αποφύγεις

### 1. Χρήση OOC στο RP Chat

Ένα συχνό λάθος των νέων παικτών είναι να γράφουν στο Roleplay (IC = In Character) chat πράγματα εκτός ρόλου (OOC = Out of Character), όπως *"Πώς κάνω craft αυτό;"* ή *"Ποιο είναι το Discord;"*.

* **Τι να κάνεις:** Χρησιμοποίησε την εντολή `/smp` αν θέλεις να παίξεις απλό Survival ή να επικοινωνήσεις OOC με άλλους παίκτες. Όταν θέλεις να επιστρέψεις στο Roleplay mode (IC), χρησιμοποίησε την εντολή `/rp`. Μπορείς να δεις όλες τις εντολές επικοινωνίας στον [Οδηγό Game Commands](https://pgglegacy.gr/blog/game-commands/).

### 2. Metagaming (Χρήση Εξωτερικών Πληροφοριών στο RP)

Πληροφορίες που απέκτησες παίζοντας στο `/smp` mode, μέσω συζητήσεων στο Discord ή χρησιμοποιώντας το map, δεν επιτρέπεται να τις χρησιμοποιήσεις όταν παίζεις στο `/rp` mode. Ο χαρακτήρας σου στο RP μπορεί να γνωρίζει μόνο πληροφορίες που έχει μάθει μέσα από το ίδιο το Roleplay.

* **Τι να κάνεις:** Διαχώρισε τις γνώσεις σου ως παίκτης από τις γνώσεις του χαρακτήρα σου. Ο χαρακτήρας σου στο RP γνωρίζει **μόνο** όσα μαθαίνει ο ίδιος εντός του Roleplay από άλλους χαρακτήρες.

### 3. Ασέβεια & Βρίσιμο (Lack of Respect)

Η τοξική συμπεριφορά, οι ύβρεις και οι προσβολές απέναντι σε άλλους παίκτες δεν γίνονται δεκτές στον server.

* **Τι να κάνεις:** Να είσαι πάντα κόσμιος και να αντιμετωπίζεις όλους τους παίκτες με σεβασμό, τόσο στο chat όσο και στο voice chat. Ο σεβασμός μεταξύ των μελών της κοινότητας είναι ο σημαντικότερος κανόνας μας!

### 4. Αγνοώντας τους κανόνες Protection / Land Claims

Μην χτίζεις μέσα ή πολύ κοντά σε περιοχές και κατασκευές άλλων παικτών χωρίς την άδειά τους. 

* **Τι να κάνεις:** Πριν ξεκινήσεις το χτίσιμο, βεβαιώσου ότι η περιοχή είναι ελεύθερη (αναλυτικά στο [Getting Started Guide](https://pgglegacy.gr/blog/getting-started-guide/)).

### 5. Παράλειψη ανάγνωσης των κανόνων

Η άγνοια των κανόνων δεν αποτελεί δικαιολογία σε περίπτωση ποινής, προειδοποίησης (warn) ή αποκλεισμού (ban).

* **Τι να κάνεις:** Αφιέρωσε 5 λεπτά για να διαβάσεις τους κανόνες στο Discord ή στο site μας πριν ξεκινήσεις την περιπέτειά σου.
