## 🗺️ <span id="cmd-travel"></span>Μετακινήσεις

| Command          | Περιγραφή                            |
| ---------------- | ------------------------------------ |
| `/spawn`         | Επιστροφή στο Spawn                  |
| `/home`          | Μετάβαση στη βάση σου                |
| `/sethome`       | Ορισμός τρέχουσας τοποθεσίας ως home |
| `/tpa [παίκτης]` | Αίτημα teleport σε άλλον παίκτη      |
| `/tpaccept`      | Αποδοχή αιτήματος teleport           |
| `/tpdeny`        | Απόρριψη αιτήματος teleport          |

## 🌍 <span id="cmd-modes"></span>Modes & Περιβάλλον

| Command   | Περιγραφή                                                         |
| --------- | ----------------------------------------------------------------- |
| `/season` | Εμφάνιση περιβαλλοντικών δεδομένων (τρέχουσα εποχή & θερμοκρασία) |
| `/smp`    | Μετάβαση σε Survival Mode                                         |
| `/rp`     | Μετάβαση σε Roleplay Mode                                         |

## 💬 <span id="cmd-chat"></span>Επικοινωνία

| Command                   | Περιγραφή                 |
| ------------------------- | ------------------------- |
| `/msg [παίκτης] [μήνυμα]` | Ιδιωτικό μήνυμα           |
| `/r [μήνυμα]`             | Απάντηση στο τελευταίο DM |
| `/anon [μήνυμα]`          | Ανώνυμο μήνυμα (RP)       |
| `/ooc [μήνυμα]`           | Out Of Character chat     |

## 🔒 <span id="cmd-safety"></span>Ασφάλεια & Προστασία

| Command              | Περιγραφή                          |
| -------------------- | ---------------------------------- |
| `/lock`              | Κλείδωμα chest/πόρτας              |
| `/unlock`            | Ξεκλείδωμα αντικειμένου            |
| `/trust [παίκτης]`   | Πρόσβαση σε κλειδωμένο αντικείμενο |
| `/untrust [παίκτης]` | Αφαίρεση πρόσβασης                 |

## 🎭 <span id="cmd-rp"></span>Roleplay

| Command             | Περιγραφή                    |
| ------------------- | ---------------------------- |
| `/identity`         | Εμφάνιση RP ταυτότητας       |
| `/me [action]`      | RP action description        |
| `/do [description]` | Περιγραφή σκηνής (RP)        |
| `/wanted [παίκτης]` | Αναφορά wanted (μόνο Police) |

## 🆘 <span id="cmd-emergency"></span>Έκτακτη Ανάγκη

| Command                     | Περιγραφή                |
| --------------------------- | ------------------------ |
| `/report [παίκτης] [λόγος]` | Αναφορά παίκτη στο Staff |
| `/helpop [μήνυμα]`          | Μήνυμα προς online Staff |

## 🎨 <span id="cmd-skin"></span>Skin

| Command                | Περιγραφή                          |
| ---------------------- | ---------------------------------- |
| `/skin url [URL]`      | Αλλαγή skin μέσω direct URL (.png) |
| `/skin set [username]` | Αντιγραφή skin από άλλον παίκτη    |
