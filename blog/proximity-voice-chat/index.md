## 🎧 <span id="vc-features"></span>Τεχνολογία & Χαρακτηριστικά

To **Proximity Voice Chat** του server μας χρησιμοποιεί προηγμένες τεχνολογίες επεξεργασίας ήχου για να προσφέρει την πιο ρεαλιστική εμπειρία Roleplay και Survival:

| Χαρακτηριστικό                | Περιγραφή                                                                                                                              |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **3D Positional Audio**       | Ο ήχος κατευθύνεται στον χώρο. Αν ένας παίκτης σου μιλάει από τα αριστερά, θα τον ακούσεις μόνο στο αριστερό σου ακουστικό!            |
| **Wall Occlusion**            | Οι τοίχοι και τα συμπαγή blocks εμποδίζουν τον ήχο! Αν κάποιος βρίσκεται πίσω από τοίχο, η φωνή του θα ακούγεται θαμπή και χαμηλότερη. |
| **Nametag Indicator**         | Εμφανίζεται ειδική οπτική ένδειξη (εικονίδιο μικροφώνου) πάνω από το Nametag του παίκτη την ώρα που μιλάει.                            |
| **Καμπύλη Μείωσης Έντασης**   | Η ένταση της φωνής μειώνεται ομαλά βάσει απόστασης (Distance Attenuation Curve) μέχρι να χαθεί τελείως στα 10+ blocks.                 |
| **Ειδική Πλατφόρμα Σύνδεσης** | Σύνδεση μέσω του δικού μας Web App απευθείας από τον browser σας, χωρίς εγκαταστάσεις.                                                 |

## 🚀 <span id="vc-guide"></span>Οδηγός Σύνδεσης (Βήμα-Βήμα)

Ακολουθήστε τα παρακάτω απλά βήματα για να συνδεθείτε στο Voice Chat μέσα σε λίγα δευτερόλεπτα:

### Βήμα 1: Εκτέλεση της εντολής στο παιχνίδι

Μπείτε στον server και πληκτρολογήστε την εντολή `/vc` στο chat.

<img src="https://pgglegacy.gr/blog/media/ProximityVoiceChat1.webp" alt="Εντολή /vc στο Chat" loading="lazy" style="display: block; margin: 20px auto; max-width: 100%; border-radius: 8px;" />

- - -

### Βήμα 2: Λήψη Συνδέσμου & Κωδικού

Στο chat θα εμφανιστεί ένας μοναδικός σύνδεσμος καθώς και ο προσωπικός σας **Session Code**. Κάντε click στο link για να ανοίξει η πλατφόρμα στον browser σας.

<img src="https://pgglegacy.gr/blog/media/ProximityVoiceChat2.webp" alt="Μήνυμα επιβεβαίωσης με Code" loading="lazy" style="display: block; margin: 20px auto; max-width: 100%; border-radius: 8px;" />

- - -

### Βήμα 3: Σύνδεση στην Web Πλατφόρμα

Στην σελίδα που θα ανοίξει, συμπληρώστε τον κωδικό σας (αν δεν έχει συμπληρωθεί αυτόματα) και πατήστε **Σύνδεση / Connect**.

<img src="https://pgglegacy.gr/blog/media/ProximityVoiceChat3.webp" alt="Web Platform Interface" loading="lazy" style="display: block; margin: 20px auto; max-width: 100%; border-radius: 8px;" />

- - -

### Βήμα 4: Παραχώρηση Δικαιωμάτων Μικροφώνου

Όταν ο browser ζητήσει άδεια πρόσβασης στο μικρόφωνό σας, πατήστε **Να επιτρέπεται (Allow)**. Είστε έτοιμοι!

<img src="https://pgglegacy.gr/blog/media/ProximityVoiceChat4.webp" alt="Έγκριση Μικροφώνου στον Browser" loading="lazy" style="display: block; margin: 20px auto; max-width: 100%; border-radius: 8px;" />

## ⚙️ <span id="vc-settings"></span>Ρυθμίσεις & Συμβουλές

<div class="blog-info-box">
  <span class="blog-info-icon">💡</span>
  <div>
    <strong>Pro Tip:</strong> Για την καλύτερη δυνατή εμπειρία, χρησιμοποιήστε ακουστικά (Headphones). Αυτό αποτρέπει την επιστροφή ήχου (Echo) στο μικρόφωνό σας και σας επιτρέπει να εκμεταλλευτείτε πλήρως τον <strong>3D ήχο</strong>!
  </div>
</div>

* **Αλλαγή Μικροφώνου:** Μπορείτε να αλλάξετε τη συσκευή εισόδου/εξόδου ήχου απευθείας από το μενού ρυθμίσεων του Web App.
* **Push-to-Talk vs Voice Activity:** Επιλέξτε αν θέλετε το μικρόφωνό σας να είναι ανοιχτό συνεχώς ή να ενεργοποιείται με το πάτημα ενός πλήκτρου.
* **Αποσύνδεση:** Αν κλείσετε την καρτέλα του browser, αποσυνδέεστε αυτόματα από το Voice Chat.
