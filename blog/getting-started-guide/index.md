## Βήμα 1: Κατέβασε το Minecraft Java Edition

Ο PGG Legacy τρέχει σε **Minecraft Java Edition 1.20.1**. Αν δεν έχεις ήδη το παιχνίδι, μπορείς να το αγοράσεις από το [minecraft.net](https://www.minecraft.net). Βεβαιώσου ότι έχεις την έκδοση **1.20.1** επιλεγμένη στο launcher σου.

## Βήμα 2: Συνδέσου στον Server

Άνοιξε το Minecraft, πήγαινε στο **Multiplayer → Add Server** και βάλε:

* **Server Name:** PGG Legacy
* **Server Address:** play.PGGlegacy.gr

Πάτησε **Done** και μετά **Join Server**. Είσαι μέσα!

## Βήμα 3: Διάβασε τους Κανόνες

Πριν κάνεις οτιδήποτε, **διάβασε τους κανόνες** του server. Μπορείς να τους βρεις στην [κεντρική σελίδα](/#rules) ή στο Discord μας. Η άγνοια των κανόνων δεν αποτελεί δικαιολογία σε περίπτωση ποινής.

## Βήμα 4: Φτιάξε τον χαρακτήρα σου

Στον PGG Legacy, κάθε παίκτης έχει έναν **RP χαρακτήρα**. Σκέψου:

* Ποιο είναι το όνομα του χαρακτήρα σου;
* Ποια είναι η ιστορία του;
* Ποιο επάγγελμα ή ρόλο θέλεις να έχεις; (έμπορος, αστυνομικός, hitman κλπ)

## Βήμα 5: Γνώρισε την κοινότητα

Μπες στο [Discord μας](https://discord.gg/Ks7NtXhtwV) για να γνωρίσεις άλλους παίκτες, να ρωτήσεις ερωτήσεις και να μαθαίνεις για τα επερχόμενα events

## Χρήσιμες Συμβουλές για Αρχάριους

* 🏠 **Φτιάξε βάση** σε ασφαλές μέρος το συντομότερο δυνατό.
* 💬 **Μίλα IC** — χρησιμοποίησε το chat για RP διάλογο, όχι OOC συζητήσεις.
* ⚔️ **Απόφυγε RDM** — κάθε φόνος χρειάζεται λόγο και διάλογο.
* 🌙 **Blood Moon** — όταν η νύχτα γίνει κόκκινη, βρες κάλυψη ή προετοιμάσου για μάχη.
* 💎 **Economy** — τα Diamonds είναι το νόμισμα του server. Κράτα τα ασφαλή!
* 🚔 **Αστυνομία** — αν σε συλλάβουν, παίξε το σκηνικό. Μην κάνεις Combat Log.
