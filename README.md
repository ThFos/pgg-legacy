## ✨ Features

### 🌍 Website
- **Responsive Design** — Πλήρως βελτιστοποιημένο για Desktop & Mobile
- **Custom Cursor Animations** — Διαδραστικές κινήσεις ποντικιού
- **AOS Scroll Animations** — Ομαλές animations κατά το scrolling
- **Live Server Status** — Εμφανίζει online παίκτες σε πραγματικό χρόνο
- **IP Copy Button** — One-click αντιγραφή της Server IP
- **SEO Optimized** — Schema.org, Open Graph, Twitter Cards, Sitemap

### 🗺️ Live Dynamic Map
- Ενσωματωμένος real-time χάρτης του server μέσω **Dynmap**
- Εμφανίζει online παίκτες, builds και περιοχές

### 🏆 Player Leaderboard
- Live κατάταξη παικτών με στατιστικά:
  - ⏱️ Playtime
  - ⚔️ Kills
  - 🎨 Player Skins

### 👮 Police Applications
- Online φόρμα αιτήσεων για το αστυνομικό σώμα του RP
- Αυτόματη επεξεργασία & αποθήκευση στη βάση δεδομένων
