## ✨ Χαρακτηριστικά (Features)

* 🗺️ **Live Dynamic Map:** Ενσωματωμένος χάρτης του server σε πραγματικό χρόνο (Dynmap).
* 🏆 **Player Leaderboard:** Live στατιστικά και κατάταξη παικτών (Playtime, Kills, Skins).
* 👮 **Police Applications:** Φόρμα αιτήσεων για το αστυνομικό σώμα του RP.
* ⚡ **Responsive UI/UX:** Πλήρως βελτιστοποιημένο για Desktop & Mobile συσκευές με custom animations.

---

## 🛠️ Τεχνολογίες (Tech Stack)

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla / ES6)
* **Backend:** PHP / MySQL
* **Integration:** Minecraft PaperMC Server API & Dynmap
